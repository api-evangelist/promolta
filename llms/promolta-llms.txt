# Promolta

> Promolta Inc. is a San Francisco Bay Area (Sunnyvale, CA) self-service video advertising
> platform. Advertisers fund campaigns to promote YouTube and other videos across Promolta's
> network of blogs, websites, games, mobile apps, and social networks; publishers in that
> network earn by distributing the sponsored video content. Campaigns can be optimized for
> views, YouTube likes, YouTube subscribers, or mobile app installs, and targeted by age,
> gender, location, and keywords. Promolta is a portfolio company of 500 Global.

**There is no public Promolta API.** As of 2026-08-12 Promolta publishes no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK in any public package registry,
no webhook catalog, and no MCP or A2A agent surface. The product is consumed exclusively
through the advertiser and publisher web dashboards at promolta.com. Do not attempt to call a
Promolta API — none is documented, and every unknown path on promolta.com answers HTTP 200
with an empty body (a catch-all), so a 200 from that host is not evidence that an endpoint
exists.

This file is generated by the API Evangelist enrichment pipeline from the public Promolta web
surface. It is not published by Promolta.

## Product

- [Promolta (advertisers)](https://www.promolta.com/): Start a video promotion campaign.
  Minimum campaign budget is $10 (per the published FAQ). Campaigns typically go live within
  one hour and always within 24 hours.
- [Publisher network](https://www.promolta.com/publisher): Join the network to distribute
  sponsored video content.
- [Advertiser login](https://www.promolta.com/advertiser/login): Advertiser dashboard sign-in.
- [Login / sign up](https://www.promolta.com/login): Account creation, including Facebook sign-in.
